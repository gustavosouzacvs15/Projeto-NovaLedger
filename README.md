# 🏁 Projeto NovaLedger — Plataforma Inteligente de Gestão Financeira

**Filosofia:** Transformar o controle financeiro pessoal e empresarial em uma experiência simples, visual e inteligente, permitindo que usuários acompanhem receitas, despesas, investimentos e metas financeiras em tempo real.

O projeto NovaLedger utiliza conceitos de Engenharia de Requisitos, Desenvolvimento Orientado a Especificações (SDD) e Design Centrado no Usuário para entregar uma solução moderna, responsiva e de fácil utilização.

---

# 🏗️ Arquitetura Padrão Ouro

O sistema é dividido em módulos especializados para garantir escalabilidade, manutenção simplificada e excelente experiência do usuário.

### Interface (Frontend)

Responsável pela interação com o usuário através de uma interface moderna utilizando:

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Chart.js

### Motor de Negócios (Backend Lógico)

Responsável pelo processamento de dados financeiros:

* Controle de receitas
* Controle de despesas
* Controle de investimentos
* Cálculo de fluxo de caixa
* Cálculo de metas financeiras
* Relatórios automáticos

### Persistência de Dados

Armazenamento local utilizando:

* LocalStorage
* Arquivos CSV
* Estrutura preparada para futura integração com banco de dados

---

# 🗺️ Objetivo do Sistema

O NovaLedger foi desenvolvido para resolver problemas comuns encontrados no controle financeiro:

* Falta de organização financeira
* Dificuldade para visualizar receitas e despesas
* Ausência de metas financeiras claras
* Controle manual de investimentos
* Falta de relatórios rápidos para tomada de decisão

O sistema fornece uma visão consolidada da saúde financeira do usuário.
